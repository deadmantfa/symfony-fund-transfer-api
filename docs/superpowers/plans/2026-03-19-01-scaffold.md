# Fund Transfer API — Plan 1: Project Scaffolding

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create a fully working Symfony 7 + PHP 8.5 + FrankenPHP project skeleton with Docker, Makefile, and all quality tooling configured and passing in CI.

**Architecture:** Symfony API skeleton with no UI layer. FrankenPHP serves HTTP. PostgreSQL 16 and Redis 7 run as Docker services. All quality gates (PHPStan 9, Rector, CS-Fixer, Deptrac, Pest, Infection) are wired up and green before any domain code is written.

**Tech Stack:** PHP 8.5, Symfony 7.x, FrankenPHP, PostgreSQL 16, Redis 7, Pest, PHPUnit, Infection PHP, PHPStan 9, Rector, PHP-CS-Fixer, Deptrac, GitHub Actions

```dockerfile

# Install PHP extensions
RUN install-php-extensions \
    pdo_pgsql \
    redis \
    intl \
    zip \
    opcache \
    sodium

# Install composer
COPY --from=composer:latest /usr/bin/composer /usr/bin/composer

WORKDIR /app

# Copy app
COPY . .

RUN composer install --no-interaction --optimize-autoloader --no-dev

# Permissions
RUN chown -R www-data:www-data /app/var
```
